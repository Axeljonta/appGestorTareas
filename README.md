# 📝 Gestor de Tareas en JavaScript

Un proyecto interactivo desarrollado en JavaScript para la gestión eficiente de tareas. Este programa te permite organizar tus actividades de forma sencilla y práctica.  Es una herramienta interactiva que se ejecuta en la consola y está pensada como un proyecto práctico para mejorar habilidades en programación estructurada y manejo de datos en arrays. 

## 🚀 Funcionalidades principales

✅ **Gestión completa de tareas**:  
   - Agrega, edita y elimina tareas según lo necesites.  

📅 **Soporte para fechas**:  
   - Añade fechas límite a tus tareas con validación automática.  

📂 **Categorías personalizables**:  
   - Clasifica las tareas en categorías que puedes crear y gestionar fácilmente.  

🔍 **Orden y búsqueda eficientes**:  
   - Ordena tareas por **nombre** o **fecha límite** usando el algoritmo **BubbleSort**.  
   - Encuentra tareas específicas mediante **búsqueda binaria**.  

📊 **Estadísticas y filtros**:  
   - Filtra tareas por categoría y obtén un resumen de las completadas.  

🖥️ **Interfaz interactiva**:  
   - Sistema de menús amigable que guía todas las acciones.

## 🛠️ Tecnologías utilizadas

- **JavaScript**: Lenguaje principal para la lógica del programa.  
- **Node.js** *(opcional)*: Para ejecutar el programa en un entorno local.
